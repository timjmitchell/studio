# F.A.Q.

# 

### Where is the documentation?

* **MIDI Guitar 3** / **MIDI Bass 3** / **MIDI Cello 3** has [extensive documentation](https://jam.live/modules/modules/).
* **MIDI Guitar 2** contains an interactive help system (click `HELP`) to get you started, and more [documentation here](https://jamorigin.com/daw).
* **MIDI Guitar 2 for iOS** has [documentation here](https://www.jamorigin.com/docs/midi-guitar-for-ios/).
* **MIDI Guitar 2 for Garageband** has [documentation here](https://www.jamorigin.com/docs/midi-guitar-for-ios/).

### How to run **MIDI Guitar** in my DAW?

The plugins run in almost all DAWs (digital audio workstations). Please refer to [the DAW guides](https://jam.live/modules/daw-guides/).

### I lost my license file for **MIDI Guitar 2** / **MIDI Bass 1**?

The license file is named `<yournamehere>.license`. You may be able to find it on the computer you originally installed **MIDI Guitar 2** / **MIDI Bass 1** on.
In the event that the file is not accessible anymore, we can provide you with a new link to redownload it. Fill out [this form](https://www.jamorigin.com/contact/) and we’ll get back to you within a week or so.
Also look [here](https://www.jamorigin.com/daw/#applylicense) for how to apply your license file.

### For general information on **MIDI Guitar**

It is recommended to visit the **Jam Origin** user forum at [jamosapien.com](https://jamosapien.com). The forum is full of useful **MIDI Guitar**-related information and like-minded users who help one another to answer questions and solve any technical issues that may arise.
