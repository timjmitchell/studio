# Keyboard Shortcuts

If you're using AbleSet with a keyboard, you can use these shortcuts to control
it:

### Global:

* `␣`: Play/pause
* `⇧ ␣`: Play
* `⇧ R`: Toggle recording
* `←`: Jump to previous song
* `→`: Jump to next song / escape current loop
* `↑`: Previous Section
* `↓`: Next Section
* `⇧ ←`: Jump to previous measure or bar
* `⇧ →`: Jump to next measure or bar
* `L`: Toggle Loop
* `⇧ L`: Toggle device lock
* `J`: Jump to the queued song or section
* `⇧ J`: Instantly jump to the queued song or section
* `C`: Cancel queued jump

### In Setlist View:

* `⌘ P`: Print the setlist
* `⇧ O`: Load a setlist

#### In the Setlist Editor:

* `⇧ H`: Toggle the visibility of skipped songs
* `⇧ S`: Save the current setlist
* `⌘ ⏎`: Save changes and exit the editor

### In Setlist and Performance Views:

* `⌘ K`: Open the dialog for adding songs

### When Lyrics Are Shown:

* `.`: Next lyrics line
* `,`: Previous lyrics line
* `B`: Scroll back to the current line
* `M`: Jump to next lyrics line and pin it
* `N`: Jump to previous lyrics line and pin it
* `⇧ M`: Toggle lyrics pinning

### In the Canvas Editor:

* `⌘ K`: Open the element search dialog
* `⌘ Z`: Undo
* `⌘ ⇧ Z`: Redo
* `⌘ D`: Duplicate selected elements
* `⌫`: Delete selected elements
