# Visual Metronome

The Visual Metronome provides visual feedback on every beat. You can use it
in setlist view, performance view, and canvases. It uses the following
indicators in order of priority, falling back to the next one if the current
one isn't available:

* The [Measure Track](https://ableset.com/docs/measure-track)
* The [Max for Live Device](https://ableset.com/docs/midi-mapping#max-for-live-device)
* The project file's time signature markers

If you don't use a Measure Track or the Max for Live device in your project,
make sure to save your project each time you change time signatures so
the Visual Metronome has access to the latest information. Otherwise, the
metronome might be off-beat.

The metronome's color always matches the current section's color.

### Using the Visual Metronome in Setlist View

To enable the Visual Metronome in your setlist, click the settings button at the
bottom left of your setlist page and enable "Show Visual Metronome". The
metronome will appear at the bottom left, in the information area:

[](/images/docs/19-visual-metronome/visual-metronome-setlist.mp4)

### Using the Visual Metronome in Performance View

To enable the Visual Metronome in Performance View, click the settings button at
the top left of the screen and enable the "Visual Metronome" option. The
metronome will appear full-screen behind all other elements:

[](/images/docs/19-visual-metronome/visual-metronome-performance.mp4)
