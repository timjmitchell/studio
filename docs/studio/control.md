# Control surfaces: what an agent can drive

What the agent can *act on* in the studio, per target (Console, Logic, MIDI gear, files), and
how far each path has been proven. This expands the execution-surfaces table in
[inventory.md §8](inventory.md#execution-surfaces). Investigation started 2026-10-12. Everything
here was found by **read-only** probing. No write has been tried yet, except the Logic click
toggle (2026-10-06).

Confidence: ✅ documented · 🔶 inferred · 🧪 tested (with date) · ❓ to test.

## 2. UAD Console

### 2.1 UA Mixer Engine (TCP 127.0.0.1:4710) — the main path

🧪 2026-10-12. Console 12.0.0, protocol 1.0.0. **The engine describes itself.** Every `get`
returns each property's `type`, `min`/`max` or enum `values`, `default`, and (for some)
`readonly: true`. The root node also lists every **command** with its arguments. The schema
is generated by `uv run scripts/ua_schema.py` into
[`data/snapshots/ua-console/engine-schema.json`](../../data/snapshots/ua-console/engine-schema.json)
(49 node types, 338 properties, 74 commands).

**Settable properties** (no `readonly` flag; 🔶 the flag is incomplete, e.g. `Version` and
`SerialNumber` carry none):

| Node | Useful writable properties |
|---|---|
| `/` (global) | `Session` (list of saved sessions, current value), `IOMapPreset`, `SampleRate`, `ClockSource`, `CueBusCount`, `TalkbackOn`, `Tempo`, `UndoRedo`, `MidiInputDevice` |
| `/devices/N` | `DimAttenuation`, `AltMonSelection`, headphone/speaker correction enables, `HPnSendPostFader` |
| `/devices/N/inputs/N` | `Mute`, `Solo`, `FaderLevel` (dB, −144…+12), `Pan`, `Name`, `Stereo`, `ChannelHidden`, `Preset`, `Isolate` |
| `…/inputs/N/preamps/N` | `Gain`, `48V`, `Pad`, `HiZ`, `LowCut`, `Phase` |
| `…/inputs/N/sends/N` | `Gain`, `Pan`, `Bypass`, `PostFaderOverride` (aux and **monitor-mix (cue) sends**) |
| `…/effects/N` | `Power`, `Preset`, `EffectName`; plugin `parameters/N`: `NormalizedValue`, `StringValue` |
| `/devices/N/auxs/N` | `FaderLevel`, `Mute`, `MixToMono`, `SendPostFader` |
| `/devices/N/outputs/N` | `Name`, `Pad`, `AltMonTrim`, `AltMonEnabled` |
| `/pluginscenes/N` | `RecalledSceneIndex` |

**Commands** (grouped; full argument list in the schema file):

| Group | Commands | Risk |
|---|---|---|
| Read / backup | `ToXML {path}`, `GetSpeakerTrims`, `Get*CorrectionSpec`, `DumpChains` | 🔶 read-only; **`ToXML` + `FromXML` could give whole-state backup and restore** for undo |
| Sessions | `OpenSession`, `SaveSession`, `SaveSessionAs`, `NewSession`, `RenameSession`, `SaveLastUsedSession` | load replaces the whole mix |
| I/O Matrix | `SaveIOMapPreset`, `RenameIOMapPreset`, `Import`/`Export` | changes what the DAW sees |
| Mixer edits | `CopyChannel`/`PasteChannel`, `MoveChannel`, `CopyInsert`/`PasteInsert`/`MoveInsert`/`ShuffleInserts`, `ClearSolos`, `ClearClips` | |
| Presets / snapshots | `SaveAsPreset`, `SaveAsSnapshot`, `ImportSnapshots`/`ExportSnapshots`, `MovePreset`, `MoveSnapshot` | |
| UI | `OpenWindow`/`CloseWindow` (Console or a plug-in), `CloseModalDialog`, `Identify` | harmless |
| **Never from an agent** | `DeleteSession`, `DeletePreset`, `DeleteSnapshot`, `DeleteFolder`, `DeleteIOMapPreset`, `AddDevice`/`RemoveDevice`, `ResetDanteNetwork`, `*test` (factory tests), `BeginSpeakerMeasurement` | destructive or factory |

Wire format for `set`, command invocation and subscriptions: see §2.2.

Other local UA services (from `~/Library/Preferences/Universal Audio/_*_tcp.json`, 🧪):
`_uamixer` 4710 (the engine), `_uapaneld` 4715, `_uadevice` 4718, `_uamixerhelper` 4720,
`_uamixerd` 4740; UAD Console itself listens on 4744. ❓ Not probed. Stay on 4710.

### 2.2 Protocol details

Not tested here yet. Sources: [fomoPhil/uad-console-mcp `docs/PROTOCOL.md`](https://github.com/fomoPhil/uad-console-mcp)
(the most complete), [raduvarga/UA-Midi-Control](https://github.com/raduvarga/UA-Midi-Control)
(the original Wireshark reverse-engineering), [jlmitch5/ApolloBot](https://github.com/jlmitch5/ApolloBot).

- ✅ Frame: `<verb> <path>[ <json-value>]\0`. Verbs: `get`, `set`, `subscribe`, `unsubscribe`,
  `post`. Unknown verbs are dropped silently. Replies carry no request id, so match them by `path`.
- ✅ **Writes target `/value`**: `set /devices/0/inputs/8/Name/value "UG 1"`. The reply echoes the new value.
  Use dB properties (`FaderLevel`, `Gain`), not the coarsely quantized `*Tapered` 0–1 versions. Booleans are JSON `true`/`false`.
- ✅ `subscribe <path>` pushes `{"path": ".../value", "data": x}` on every change. That gives
  live feedback, e.g. to notice Tim moving a fader in Console.
- ⚠️ **The engine doesn't enforce `readonly`** (uad-console-mcp: a `set` on `DeviceHwID` was
  accepted). The allow-list has to live in our client.
- ✅ Monitor output: find it by the presence of `CRMonitorLevel`, not by index. Monitor controls are `Dim`,
  `Mute`, `Mono`, `AltMonitor`. Output routing to the main or a monitor mix: `outputs/N/MixInSource` = `"mon"` / `"cue"` (ApolloBot).
- ✅ Plugin `parameters/*` nodes appear only after a plugin loads. Poll for them.
- ❓ How the root **commands** are invoked (probably `post`, which is undocumented). Whether
  `set /Session/value "<name>"` loads a session. Cue mirror control (may live only in the `.ini`).
  `propfilter` syntax. Headphone level (no property found).
- uad-console-mcp itself is an MCP server (22 tools, readonly / safe / full modes, writes
  throttled to 10/s, monitor capped at −6 dB). Options: adopt it, or crib its safety model
  into our own small client. Its readonly mode is a cheap first step.

### 2.3 Console MIDI

✅ [MIDI Settings Panel](../../data/manuals/controllers-interfaces/UAD-Console/36-midi-settings-panel.md):
Console takes MIDI for exactly two things, **tap tempo** (note or CC) and **Plug-In Scene
recall** (note or program change; scenes 1–128 = PC 0–127). No faders, mutes or sends by MIDI.
🧪 `MidiInputDevice` is currently **empty** (no source chosen). Candidates are already
present: `IAC Driver StreamDeck UAD`, `IAC Driver Bus 1`, `Network Daw Control Session`.

### 2.4 Console keyboard shortcuts

✅ Few, and they need Console focused: Cmd+F10/F11/F12 monitor mute / down / up (the
Fn variant depends on the macOS function-key setting), ⌘I show/hide channels, Shift+W
floating windows, ⌘⌃←/→ switch device tab, ⇧⌘F full screen. The engine reaches everything
these do, so shortcuts are a fallback.

## 3. Logic Pro

🧪 Logic 11.2.2. No AppleScript dictionary (no `OSAScriptingDefinition`). No project was open at probe time.

### 3.1 Accessibility (UI scripting)

🧪 Proven for the control bar and track list. See [Logic Field Notes §4](../../data/manuals/daw-video/Logic-Pro-Field-Notes.md).
Reads back state, so it closes the loop for transport.

### 3.2 MIDI in → Controller Assignments

🧪 MIDI ports present: **`Logic Pro Virtual In`** (Logic's own virtual input, no IAC needed),
`IAC Driver Bus 1`, `IAC Driver StreamDeck UAD`. 🧪 Logic's controller file
`~/Library/Preferences/com.apple.logic.pro.cs` (binary, 75 KB, updated 2026-10-12) has
~380 assignment records and names: VE-500, Launchkey Mini MK4 25, IAC Driver, StreamDeck
UAD, UM-ONE, MPK249, iPad, Network DAW Control Session, plus control surfaces **HUI**,
**TouchOSC**, **Logic Remote**. ❓ What each assignment does: read it in Logic's Controller
Assignments window (Expert view), since the file isn't parsed.

With Learn, any key command can be bound to a note or CC on `Logic Pro Virtual In` and
triggered without focus. One-way: no confirmation that it fired.

### 3.3 Key commands

🧪 Active set: the stock **U.S.** set, untouched (`lastSelectedKeyCommandsPath`,
`lastSelectedKeyCommandsTouched = 0`). The 856 live bindings are in `com.apple.logic10.plist` →
`KeyCommands`, keyed by numeric command ID (`{Modifier, Key, CharCode}`). The plist has no
command names. To get names: Key Commands window > *Copy Key Commands to Clipboard*, or read
menu items' `AXMenuItemCmdChar` (Field Notes §4). Keystrokes go to the focused pane, so prefer
menu clicks or MIDI.

### 3.4 Control surface protocols and OSC

🧪 Logic listens on **UDP 7000** (OSC, used by Logic Remote / TouchOSC) and TCP 49828, and
Bonjour advertises `_osc._udp`. MCU/HUI emulation over a virtual port would give **track
names, fader positions, transport state as feedback**. See [uad-midi-ai](../research/uad-midi-ai.md).

- 🔶 OSC is fragile. Logic accepts it only from Bonjour-advertised TouchOSC/Lemur surfaces,
  and OSC learn reportedly broke years ago ([cycling74 thread](https://cycling74.com/forums/controlling-logic-pro-x-through-osc)).
  Logic Remote uses Apple's private Multipeer protocol. Neither is a practical API.
- ✅ **Scripter** (JavaScript MIDI FX) sees only its track's MIDI stream and plug-in parameters. It has no project or mixer access.
- ✅ No CLI. Logic 12 (Jan 2026) added no scripting API.
- Existing MCP: [MongLong0214/logic-pro-mcp](https://github.com/MongLong0214/logic-pro-mcp)
  combines CoreMIDI, Accessibility, CGEvent, a registered MCU surface (faders), a Scripter insert
  (plug-in params) and MIDI key commands, and reports each action as confirmed / uncertain / failed. It targets Logic
  12.3, but we're on 11.2.2. Worth reading for its layering even if we don't install it (its install uses Homebrew).

### 3.5 Project files

🧪 `.logicx` bundles: `Alternatives/NNN/MetaData.plist` (sample rate; ✅ also tempo, key,
time signature, track count, audio files), `ProjectData` (binary; `strings` finds plugin names;
[logicx-analyzer](https://github.com/geoffmyers/logicx-analyzer) decodes ~60%). Read-only:
never write into a bundle.

## 3a. LUNA

🧪 2026-10-12, LUNA 3.1.0. No AppleScript dictionary. Windows and menus (File, Track, Mixing,
Assistant, Transport, Navigation…) are readable via Accessibility. ✅ MCU control surfaces (up
to six) and key commands ([LUNA 3.0 manual](../../data/manuals/plugins/LUNA-3.0-Manual.md)).
Sessions in `~/Music/LUNA Sessions`. `LUNAPrefs.json` shares Console's prefs keys (shared code base 🔶).

**LUNA drives the same UA Mixer Engine.** It holds two connections to 4710, and the engine
reports `OverridingApp = "LUNA"`. LUNA also listens on 4715, 4717, 4718, 4740, 4743 (the
`_uapaneld`, `_uadevice`, `_uamixerd` services in the prefs folder). Not probed.

**Console Tracking Mode** (snapshots `ua-console/2026-10-12_2221` on → `_2226` off):

- 🧪 **On:** the Console mix is untouched. Only `Session` goes blank (dirty), and `Tempo` = LUNA's (110).
  ✅ Console works as before; LUNA doesn't mute or unmute Console channels on record-arm.
- 🧪 **Off:** LUNA takes over. It **muted 8 inputs** (A1, A3, A7, A8, x8 VIRTUAL 1/3, B1, Twin X VIRTUAL 1)
  and **set their sends to −144** (off), including monitor-mix sends to CUE 2 (in-ears) and CUE 3 (wedge) and to AUX 1.
  Monitor level −43 → −35.5 dB on both units (❓ LUNA, or the knob).
- ⚠️ Turning Console Tracking off **empties the in-ears and wedge mixes** for those inputs.
- ❓ Does turning it back on restore them?
