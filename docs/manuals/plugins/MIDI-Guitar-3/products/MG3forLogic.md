# MIDI Guitar 3 for Logic

Recommended for native Apple DAWs/hosts and AUv3 users

If you exclusively use Apple DAWs (**Logic Pro**, **MainStage**, **GarageBand**), and AUv3 plugins, this distribution of **MIDI Guitar 3** is recommended.

The AUv3 plugin version of [**MIDI Guitar 3**](https://jam.live/products/MG3/) is distributed on the [Mac App Store](https://jam.live/downloads/).

It differs from the main **MIDI Guitar 3** distribution in the following ways:

* **AUv3 sandboxed**:
  It has more restricted access to macOS's file system and resources, and thus can only load third-party AUv3 plugins that also employ restricted sandboxes.
* **Direct audio hardware access**:
  Unlike the main **MIDI Guitar 3** distribution when used in Native Apple audio software, this AUv3 plugin version is entitled to directly access audio hardware, which makes it wonderfully convenient to use hexaphonic pickup hardware within compatible DAWs.
* **Automatic updates**:
  The macOS App Store delivers automatic update notifications so you'll always have the latest version available.
