# Network Panel

# Apollo x16D and E Series Network Settings

Network settings for Dante network Apollo devices are included on the Network panel. For the most part, these settings are informational.

![dante-network-settings.png](https://help.uaudio.com/hc/article_attachments/37673953962900)

## Network Interface

This lets you select the network interface which your computer uses to connect to the Dante network. connected.

## Dante Controller (Launch)

Click this button to launch Dante Controller software.

## Dante Patent Information (More Info)

Click this button to open a web site with the patent information for Dante software.

## Dante Discovery (Refresh)

Click this button to requery the network for Dante devices and refresh the panel.

## Dante Network Settings

The Dante Network Settings row shows information about the network settings for all connected Apollo x16D and E Series devices. These network settings are also displayed in Dante Controller. All fields in this display are read-only, except Reset.

## Reset

If you need to reset your network settings for an Apollo x16D, click Reset. When you tap the Reset button, a warning appears that audio will be interrupted. All network settings are reset after you click OK.

**Tip:** For example, if the IP address of your Apollo device has been set to a static IP address that you don't know, you can reset the network settings.
