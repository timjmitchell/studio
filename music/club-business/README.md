## How the sessions fit together 🔶

Inferred from file dates, sample rates and LUNA's audio metadata. Tim to confirm.

1. **Tracking, 2024 (Logic, 48k).** Each song has a `<name> 48.logicx` with dated
   alternatives from Sep 2024 to Jan 2025.
2. **LUNA sessions.** Each song also has a LUNA session (~210–230 audio files). It holds parts
   recorded through the Apollo (files named after Apollo inputs, `A MIC/LINE 3`, `A LINE 5`, …),
   comps imported from Logic (`… - Comp A.wav`), and frozen BGV stacks. It contains both 44.1k
   and 48k audio.
3. **Mixing, Oct–Nov 2025 (Logic).** Mixes are bounced to each Logic project's `Bounces/`
   folder as `<song>_mix_YYMMDD[-tag].wav`. Tags `tape`, `notape` and `tapeonly` look like A/B
   tests with tape emulation on and off.
4. **EP comparison (LUNA).** Those bounces were imported into `Club-business-ep-mix.luna`.
5. All the Logic and LUNA sessions were saved again on **2025-12-19**.
