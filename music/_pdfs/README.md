# music/_pdfs/

PDFs for songs: chord sheets, tabs and scores (e.g. Ultimate Guitar printouts). **Not tracked
by git.** Only this README is. The PDFs are often image-only and copyrighted, and can be
downloaded again.

```text
music/_pdfs/
  <project>/<song>/     same slugs as music/<project>/<song>/
```

The song doc lists its PDFs in its **Files** table and links here. Text worth keeping
(chords, a structure, notes) goes in the song folder as Markdown.
