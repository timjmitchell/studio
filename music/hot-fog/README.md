# Hot Fog

Band project. One folder per song. The song doc (`<song>.md`) is the source of truth for the
song: key, tuning, tempo, Logic project, Drive links, and recordings.

- **Logic projects:** `/Volumes/Samsung_X5/Hot Fog/` (the drive must be mounted)
- **Google Drive:** [New- 3rd Album](https://drive.google.com/drive/folders/1pwXELsp61t3Q_IKaaypZWK1Pe1tpIrxq) ·
  [Song Ideas](https://drive.google.com/drive/folders/1NB4wCEdgy-DcZiaNZ8BjUXcM90IvvNqX) (band demos) ·
  [Bounces](https://drive.google.com/drive/folders/1ZpOHiN-H0CgMdSz5avuCFcaQ91cpVmCv)
- **Bounces:** export from Logic to the Drive Bounces folder as
  `<song-folder>_<YYYY-MM-DD>_<tag>.mp3`, then run `uv run scripts/sync_bounces.py`. It adds
  a row to the song doc's Recordings table.
