# Studio Repository

This repository sits on the studio Mac Studio, and its purpose is to manage all things music:

- Help, assistance, and scripting with Logic Pro, UAD LUNA, UAD Console
- File system management
- Compound scripts to launch multiple apps
- Managing metadata for songs and projects across DAW sessions, music notation, lyrics, etc.

## Layout

| Folder | What's in it |
|---|---|
| [`music/`](music/README.md) | My projects and songs: one folder per song |
| [`docs/studio/`](docs/studio/overview.md) | How the studio is set up: start with the [overview](docs/studio/overview.md) |
| [`docs/research/`](docs/research/) | Research notes |
| [`data/inventory/`](data/inventory/README.md) | Structured gear and wiring data |
| [`data/manuals/`](data/manuals/INDEX.md) | Gear and software manuals (Markdown) |
| `scripts/`, `kb/` | Tools and the search index |
